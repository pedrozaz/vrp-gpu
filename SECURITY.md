# Security Policy

## Supported versions

VRP-GPU is pre-release software and currently has no published, supported
version. This section will be updated when the first crates.io release is made.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/pedrozaz/vrp-gpu/security/advisories/new)
to include reproduction steps, affected revisions and the expected impact.

Reports will be acknowledged when reviewed. A remediation timeline depends on
severity and maintainer availability; no response-time guarantee is made during
the alpha phase. Confirmed fixes will be disclosed after a patched release or
after affected users have had a reasonable opportunity to update.
